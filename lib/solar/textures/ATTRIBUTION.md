# Planet maps

2K maps by **Solar System Scope / INOVE**, downloaded unchanged from
https://www.solarsystemscope.com/textures/ on 2026-09-18.
Licensed under **Creative Commons Attribution 4.0 International**:
https://creativecommons.org/licenses/by/4.0/.

These maps use NASA imagery with artistic color adjustments and reconstructed terrain.
They illustrate surfaces, not current weather, seasonal coverage, or exact rotational phase.
The application credits the creator and license in Solar System Lab → Lab notes.
